
# Space Invaders

A browser-based recreation of the classic Space Invaders arcade game,
built with JavaScript, HTML Canvas and CSS.

Developed as an academic project at Universidad Rey Juan Carlos (URJC).

## Overview

Control a spaceship, shoot incoming invaders, avoid enemy projectiles,
and survive as the alien formation advances.

The game includes a title screen, gameplay and game-over states,
score tracking, sound effects and pause functionality.

## Features

- Real-time gameplay rendered using HTML Canvas
- Player movement and projectile mechanics
- Enemy formations and movement
- Collision detection between game entities
- Score tracking and game-state management
- Sound effects and audio controls
- Pause, restart and title-screen functionality
- A frame-based update and rendering loop

## Controls

| Key | Action |
| --- | --- |
| Left / Right Arrow | Move the player |
| Space | Shoot |
| Enter | Start or restart the game |
| Escape | Pause or resume |
| M | Toggle audio mute |

## Getting Started

Open https://diegopalenciamartinez.github.io/space-invaders-web-game/

If that isn`t working:

1. Clone or download this repository.
2. Keep the `audio/` and `img/` asset directories alongside the
   HTML, CSS and JavaScript files.
3. Open `index.html` in a modern web browser.
4. Press Enter to start playing.
